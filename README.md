# Skin Clean — Клиника эстетической косметологии

Премиальный веб-сайт клиники эстетической и аппаратной косметологии **Skin Clean**.

## Возможности
- ✨ Современный премиальный дизайн в теплой эстетике (Editorial & Minimalist)
- 📸 Интерактивная галерея процедур и результатов До/После
- 🎯 Специальные предложения и акции
- 🛡️ Стандарты клинической безопасности с лицензиями и сертификатами
- 📅 Модальное окно онлайн-записи на приём и консультацию
- 📱 Полная адаптивность (Desktop, Tablet, Mobile)
- 🖼️ Интерактивная замена и загрузка фотоматериалов в слоты

## Стек технологий
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- Motion (Framer Motion)

## Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build
```
